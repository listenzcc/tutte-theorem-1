Tutte 嵌入定理：闭环钉在凸多边形上，内部就能摊平

1963 年 Tutte 的 How to draw a graph 给出一个构造性的平面嵌入方法。放到三角网格上读， 它回答的正是 UV 参数化里那个最基础的问题：什么时候摊平一定不会翻面。

定理的两个前提

  • 边界：闭环的顶点被钉到一个凸多边形的边界上，顺序一致。
  • 内部：每个内部顶点的 UV 是它邻居 UV 的严格凸组合——权重全为正、和为 1。

两条同时成立，得到的分片线性映射就是全局单射，一个三角形都不会翻。这是充分条件： 前提破了不保证立刻出事（实测里有 709 条权重非正却 0 翻面的例子），但保证没了。

Stanford Bunny：拓扑先过关，才谈摊平

兔子是带 4 个洞的开曲面（χ = −2）。从种子点按 BFS 跳数扩张取区域，先判 χ 和边界环数， 合法了才解 Tutte 嵌入。可以亲眼看到"合法半径不连续"这件事。

配置（种子 = 耳朵尖）面数χ翻面

半径 20，权重换成余切178310

五角星的 14 个翻面全部堆在凹角上；余切权重那行有 709 条边权重非正，这一例却一个翻面都没有。 定理不管的另一件事是畸变：面积比的中位数是 −4.08（约 16 倍压缩），四分位距跨 9 个 log₂ 单位。

本地运行

三个页面都是单文件、零依赖，直接双击打开即可。bunny-tutte.html 例外：它要 fetch 加载 model/bunny_small.obj，在 file:// 下会被浏览器拦截，需要起个本地服务：

python -m http.server 8765
# 然后打开 http://127.0.0.1:8765/index.html

页面状态可以用 URL 参数固定，方便复现和分享：

?seed=ear&hop=10&shape=circle&weight=mvc&view=tex
